📦 Виджеты

1. Collapse
Сворачивающийся контейнер на чистом JS. Плавное раскрытие через `max-height` + `scrollHeight`.

1. Callback Chat
Виджет обратной связи. Красная круглая кнопка, при клике — выезжает окно чата.

1. Liker
Кнопка лайка с анимированными сердечками. Используется Web Animations API, 4 случайные траектории, 500ms, ease-out.

🛠 Стек
- Webpack 5
- Vanilla JS (без jQuery)
- Web Animations API
- CSS transitions
